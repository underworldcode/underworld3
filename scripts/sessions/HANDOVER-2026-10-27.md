before setup): redundant MUMPS LU with null-pivot detection (ICNTL(24))
replaces the dense SVD at the same V-cycle count; whole solve 231/245/364 s
(SVD) against 8.1/5.1/3.7 s (MUMPS) at 612 coarse cells, np 8/16/32; 1.6-2.2x

## Rebuilding the environment

```bash
. /mnt/data/lmoresi/hyperion-env.sh      # or set by hand, below
export PIXI_CACHE_DIR=/mnt/data/lmoresi/cache/pixi
export RATTLER_CACHE_DIR=/mnt/data/lmoresi/cache/pixi
export XDG_CACHE_HOME=/mnt/data/lmoresi/cache/xdg
export UW_JIT_CACHE_DIR=/mnt/data/lmoresi/cache/uw-jit
export TMPDIR=/mnt/data/lmoresi/tmp
export OMP_NUM_THREADS=1
git clone https://github.com/underworldcode/underworld3 && cd underworld3
git worktree add .claude/worktrees/<name> <branch>; cd .claude/worktrees/<name>
echo dev > .pixi-env; pixi install -e dev && ./uw build
```

After the reimage also: `crontab /mnt/data/lmoresi/crontab.backup` and the
`hyperion-env.sh` line in ~/.bashrc (see /mnt/data/lmoresi/HYPERION.md), if
/mnt/data survives.
