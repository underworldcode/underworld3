# Underworld3 v3.2.0

## Highlights

- **Free surface in three dimensions on a spherical shell.** Surface height relaxes toward the
  equilibrium topography implied by the stress field, using an exponential integrator that is
  L-stable and cannot overshoot. The scheme is now dimension-general. *Preview: the method and its
  validation are written up in full, but there is no runnable example yet.*

- **The viscoelastic-plastic regressions reported at v3.1.0 are fixed.** All seven tests suspended
  for that release now pass, without the tests being altered — the fixes came from #493 (Stokes
  `uu_G3` transposed tangent and TI un-frozen Picard, closing #457 at source), #535 (TI-VEP
  yield-limited weak-plane viscosity) and #475 (`yield_anchor`), closing #390.

- **Full multigrid preconditioning is now Supported**, the only capability promoted since v3.1.0.
  It keeps the Stokes velocity solve at a steady ~5 iterations as the mesh distorts, where the
  algebraic alternative runs a volatile 64–131. The gain is predictability rather than raw speed.

- **Faults as real discontinuities in the mesh**, rather than smeared weak zones. A fault is
  specified once — a trace, its place in a hierarchy, the properties it carries — then realised
  either as a split-node cut with node-pair contact laws or as a volumetric weak plane. The largest
  single body of work this quarter. *Preview.*

- **Particle proxy updates are 17–80× faster.** The `IndexSwarmVariable` proxy update was
  vectorised (#374), which shows up directly in any multi-material model that carries
  material indices on a swarm.

- **A materials registry that separates what a material is from where it is**, so one rheology can
  be attached to particles or to regions without being rewritten.

- **A rebuilt container that cannot drift from the development environment.** Two-stage pixi build,
  multi-architecture (amd64 and arm64), resolved from `pixi.lock` — the drift between container and
  Binder that broke the v3.1.0 container build is no longer possible. Automated Gadi/HPC images
  alongside it.

- **Fifteen fixes to collective participation under MPI**, covering the failure mode where one rank
  takes a shortcut and every other rank waits forever in the matching collective. Includes the
  empty-rank swarm-save deadlock (#680).

## Bug Fixes

- Point evaluation recovered boundary-face query points that `DMLocatePoints` silently dropped on
  quadrilateral and hexahedral meshes (#391, #392)
- `read_timestep` now keeps one coordinate frame across sessions — DG0 fields no longer collapse on
  reload (#398, #269)
- The MMPDE mover was a silent no-op on graded meshes; a per-cell collapse floor fixes it (#420, #419)
- Finite SPD fallback for fully-degenerate metric evaluations in MMPDE (#368, #352)
- Swarm save no longer deadlocks when a rank holds no particles, and `estimate_dt` no longer crashes
  on reshape (#680)
- Cell-family detection corrected on empty MPI ranks (#691)
- Parallel plex-point to coordinate-row mapping in kd-tree and face navigation (#363, #360)
- Swarm proxy refresh under an active units model (#434, #426)
- Three-dimensional boundary reaction flux recovery (#404)
- Seam-cone reconciliation and recovered orientation — parallel finite elements now work on placed
  meshes (#521, #520)
- `GenericFluxModel` flux storage preserves symbolic field dependencies (#455)
- `flux_jacobian` is settable, for custom Jacobian tangents (#362)
- The SNES converged-reason table was off by one against PETSc (#444)

## New Features

- Geoid and self-gravity postprocessing for spherical shells, with a cylindrical-annulus
  counterpart and a reaction-based shell projection (#591, #648, #686)
- Zhong (2008) propagator-matrix analytic response (#594)
- `dmfield_evaluate` exposed from PETSc (#436)
- Mesh-files-only internal spherical-shell generation (#592)
- Custom multigrid parallel support with NVB adapt-on-top (#369, #365)
- Measured point-location capability with a NaN/RBF fallback ladder (#395, #392)

## Improvements

- `IndexSwarmVariable` proxy updates vectorised — 17 to 80 times faster (#374)
- Adaptation and redistribution renamed for intent: `node_redistribution` alongside an engine-less
  `adapt()` (#372)
- Solve reporting is on by default, with bounded and resumable difficulty solves (#377)
- Style gates in CI: a deprecated-pattern scanner with an allowlist ratchet (#364)

## Breaking Changes

- The `Null_Boundary` fake natural BC, and the label it was built on, are removed (#503)
- `synchronised_array_update` now performs a collective dirty-variable flush, replacing rank-local
  event replay (#383, #379)
- Rotated and block constraints are now mutually exclusive (#590)
- `SemiLagrangian` no longer accepts the unused `swarm_degree`, `swarm_continuous` or `_workVar`
  arguments (#705, #704)
- Slip normals are taken per boundary; the deprecated `Gamma_P1` path is gone and the mesh factories
  no longer recommend it (#659, #654, #538)
